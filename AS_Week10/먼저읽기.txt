심화전공실습 10주차 실습 자료
비디오 처리와 객체 추적

처음 실행하는 순서 (Windows)
1. ZIP 파일을 다운로드하고 [모두 압축 풀기]를 선택하세요.
2. Python이 설치된 PC에서 SETUP.bat를 더블클릭하세요.
   Python 3.11 또는 3.12를 권장합니다. 처음 패키지를 설치할 때는 인터넷이 필요합니다.
3. 설치 완료 후 RUN_PRACTICE.bat를 더블클릭하세요.
4. 메뉴에서 1, 2, 3, 4를 차례로 실행하세요.
5. 재생을 중지할 때는 영상 창을 클릭한 후 q 키를 누르세요.

메뉴와 강의자료 연결
1번: 동영상 열기, 프레임 읽기, FPS 확인 (슬라이드 7~11)
2번: 프레임 차분, 이진화, 잡음 제거 (슬라이드 12~17)
3번: MOG2, 그림자 후보 제외, 영역 검출 (슬라이드 18~27)
4번: 중심점 연결, ID 유지, 결과 저장 (슬라이드 28~39)

포함된 입력 데이터
data/vtest.avi: 강의자료와 같은 OpenCV 예제 동영상
원본 768×576, 10 FPS, 795프레임 (약 79.5초)
실습 2~4번은 가로 640픽셀로 조정하여 처리합니다.
학생이 별도 영상을 촬영하거나 준비할 필요가 없습니다.

실행 결과
4번 메뉴를 실행하면 output 폴더가 자동으로 만들어집니다.
output/tracking_result.avi: ID와 궤적이 표시된 영상
output/tracks.csv: 프레임별 중심 좌표와 바운딩박스 정보
같은 이름의 기존 결과는 덮어씁니다. 비교할 결과는 먼저 파일명을 바꾸세요.

결과를 미리 확인하려면
examples/tracking_preview.png: 실행 화면 예시
examples/tracks_example.csv: 처음 120프레임 구간의 좌표 예시
미리보기 이미지는 프레임 160, CSV 예시는 프레임 30~119 구간입니다.
두 예시는 같은 시점을 가리키는 자료가 아닙니다.

간단한 비교 실습
1. 최소 면적을 200, 500, 1200으로 바꾸고 작은 대상과 잡음을 비교하세요.
2. 최대 연결 거리를 30, 60, 100으로 바꾸고 ID 연결 상태를 비교하세요.
3. 같은 영상을 사용하고 한 번에 한 가지 설정만 바꾸세요.
명령어와 전체 설명은 README.md에 있습니다.
전체 알고리즘 구현과 CentroidTracker 클래스는 common.py에 있습니다.

실행이 안 될 때
- ZIP 안에서 바로 실행하지 말고 모두 압축을 푼 뒤 실행하세요.
- Python이나 py 명령을 찾지 못하면 Python 설치 상태와 런처를 확인하세요.
- cv2 오류가 나면 SETUP.bat를 다시 실행하세요.
- 영상 창이 나타나지 않는 원격 환경에서는 README의 --no-gui 실행 방법을 사용하세요.

결과 해석
이 실습은 움직이는 영역을 찾는 교육용 예제입니다.
사람의 종류를 인식하거나 실제 사람 수를 정확하게 세는 시스템은 아닙니다.
교차·가림·영역 병합과 분할에서 ID가 달라질 수 있습니다.
발표하거나 별도 결과물을 제출할 필요는 없습니다.
